ИИ использовался для:

- JS-анимаций: бесконечного роста и уменьшения колонок из точек с ограничением высоты, чтобы они не перекрывали содержимое.
- Проверки проекта: структуры папок, относительных путей, подключения файлов и сборки через Vite.
- Расчёта rem: настройки размеров и единой системы отступов для десктопной и мобильной версий.
